# PRODUCT REQUIREMENT DOCUMENT

### 2. 배경 및 목적 (Background & Goals)
* **배경 (Background):** 다수의 수출입 건을 동시 진행 시, 각 건의 진행 상황, 남은 단계, 지연 사유 등에 대한 고객/이해관계자의 반복 문의에 개별 대응하는 업무 부담이 가중됨.
* **목적 (Goals):** 직선 그래픽 기반의 직관적 진행률 시각화 페이지와 고유 QR/링크 자동 발송, 실시간 변동 알림 체계를 구축하여 커뮤니케이션 공수를 대폭 절감하고 정보 투명성을 확보함.

### 3. 성공 지표 (Success Metrics)
| 구분 | 지표 (Metric) | 목표치 / 비고 |
|---|---|---|
| **주요 지표 (Primary)** | QR / 링크 발송 성공률 | 100% (지정 유저에게 정확한 접근값 전달) |
| **주요 지표 (Primary)** | 선적 정보 실시간 반영률 | 선적/운송 정보 변동 시 즉시 시각화 연동 |
| **보조 지표 (Secondary)** | 진행 상황 단순 문의 감소율 | 기존 대비 50% 이상 감소 |
| **보조 지표 (Secondary)** | QR / 링크 조회율 (Open Rate) | 수신자 조회율 80% 이상 달성 |

### 4. 타겟 유저 및 유저 스토리 (User Stories)
* **[물류 담당자]** “선적이 시작되면 별도 작업 없이 자동으로 고유 QR과 링크가 생성되어 수입자에게 발송되기를 원한다.”
* **[수출자 / 수입자]** “별도 회원가입 및 로그인 없이 QR 스캔이나 링크 클릭만으로 배의 현재 위치(%)와 예상 도착일을 한눈에 보고 싶다.”
* **[수출자 / 수입자]** “운송 지연이나 경로 변경이 발생할 경우 자동 알림을 통해 변동 사항과 원인을 미리 파악하고 대비하고 싶다.”

### 6. 예외 처리 및 고려사항 (Edge Cases)
* **발송 실패 대응:** 수신자의 이메일 주소나 전화번호 오류로 자동 발송이 실패할 경우, 시스템 담당자 화면에 즉시 알림을 노출하고 수동 재발송 기능을 제공함.
* **지연 사유 미입력:** 일정 연장/지연이 발생하였으나 사유가 입력되지 않은 경우, 기본값으로 '운송사 및 현지 포트 확인 중' 메시지를 자동 표시함.
* **보안 및 접근 권한:** 로그인 없는 접근을 지원하므로, 추측이 불가능한 난수화된 보안 토큰(예: `domain.com/track?token=a8f9x2...`)을 적용하여 타인의 무단 접근을 방지함.

### 7. 범위 외 사항 (Out of Scope)
* **실시간 GPS 자동 연동:** 1차 버전에서는 선사/항공사 API 연동을 통한 실시간 위치 자동 수집은 제외하며, 담당자의 상태 입력/엑셀 업로드/기본 API 연동 방식으로 운영함.
* **모바일 앱(App) 개발:** 별도 모바일 앱 설치 없이 스마트폰 및 PC의 웹 브라우저에서 바로 확인할 수 있는 반응형 웹(Responsive Web)으로만 제공함.
* **실시간 커뮤니케이션:** 수입자와 수출자 간 서비스 내 실시간 채팅 또는 댓글 작성 기능은 1차 스코프에서 제외함.
